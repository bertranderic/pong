# Pong

Petit jeu de Pong en Python avec Pygame.

## 🚀 Fonctionnalités

- balle et raquettes animées
- collisions et score
- écran de game over
- sons et arrière-plan personnalisés

## ▶️ Lancer le jeu

Prérequis : Python 3.10+.

```bash
pip install -r requirements.txt
python pong.py
```

## 🎮 Contrôles

- Flèche haut : monter la raquette
- Flèche bas : descendre la raquette

## 📁 Structure

- pong.py : logique principale du jeu
- assets/ : images et sons
- requirements.txt : dépendances Python
